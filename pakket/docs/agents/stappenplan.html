Wat vond hij al?

15 min

Sluit Claude Code eerst af en start hem opnieuw. Pas dan zijn de reviewer en de hooks geladen. Laat daarna de reviewer jullie recente werk toetsen aan de regels die jullie net kozen. Gebruik de naam van jullie hoofdbranch.

Terminal
claude
In Claude Code
Laat de reviewer-subagent de laatste twintig commits op main toetsen aan REVIEW.md en docs/agents/risico.md. Meld alleen wat er echt tegenin gaat, met bestand en regel.
VerwachtIets waar je van schrikt, of niets. Allebei is een uitkomst.

Beoordelen en nulmeting

20 min

Lees AGENTS.md en risico.md samen. Kan iedereen uitleggen waarom een regel op "niet meer dan nu" staat? Leg daarna in je eigen terminal de nulmeting vast. Via Claude Code weigert de grens-hook dat, omdat de agent niet zelf bepaalt waartegen hij gemeten wordt.

Terminal
bin/meting --nulmeting git add -A && git commit -m "Harnas van De Werkplaats"
Klaar alsmeting-nulmeting.txt in de commit staat. Vanaf nu laat de klaar-hook de agent niet stoppen zolang de meting rood is.

6

Plant een fout

40 min

Eén persoon bouwt een fout in op een branch en zegt niet welke. Kies een plek die jullie kennen. Een ander laat de reviewer kijken, in een nieuwe sessie.

Een scope wegEen where op klant of tenant verdwijnt uit een query.
Een rol te ruimEen policy of authorize laat een lagere rol toe.
Een stille rekenfoutEen gewicht, afronding of korting telt net anders.
Oude dataEen pad dat alleen oude data nodig heeft, valt weg.
Een verkeerde volgordeTwee stappen of een override en een berekening wisselen om.
Terminal, de planter
git switch -c pr/opschonen
Bouw de fout in, en dan
git commit -am "Code opgeschoond"
In Claude Code, de ander

Gevonden

Hoe lang deed hij erover? Hoe lang zou een mens erover doen?

Gemist

Schrijf in risico.md of REVIEW.md waarom het fout is. Start een nieuwe sessie en vraag het opnieuw. Nu wel?

Zonder en met

25 min

Als er tijd is. Twee mensen pakken hetzelfde kleine ticket, de een zonder harnas, de ander met. Leg daarna de diffs naast elkaar.

Terminal, zonder harnas
git worktree add ../zonder-harnas main cd ../zonder-harnas && claude
Daarna, in beide mappen
git diff --stat
VerwachtWelke raakte meer bestanden aan? Paste een van beide een test aan, of meldde hij te vroeg klaar?
