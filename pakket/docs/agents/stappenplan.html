Nulmeting vastleggen

5 min

De nulmeting is "nu". Vanaf dit moment mag de agent niet stoppen zolang de meting rood is.

Terminal
bin/meting --nulmeting git add -A && git commit -m "Harnas van De Werkplaats"
Klaar alsmeting-nulmeting.txt in de commit staat. Start daarna claude opnieuw, want hooks worden bij de start gelezen.
